# Roguelike Project

Developed with Unity (6000.0.31).<br>
This was a solo term project for a programming course at Bow Valley College, and my first project in unity of this scale. I decided to create a simple turn-based dungeon-crawler, and experiment with enemy AI decision-making.

## Description
The player will control a party of adverturers through a series of rooms. 

As this is an “endless” game, the player's goal is to make it through as many rooms as possible. Some fun stats will be presented at the end of each run!
